# Вайб Ресейл

**[Открыть сайт и каталог](https://supernovvvvvachuu-droid.github.io/vibe-resale/?v=20261127-3#/catalog)**

Тесты и вещи по эстетикам. Публикация объявлений через GitHub Issues.

В `catalog.json` добавлены 16 настоящих вещей владельца, фотографии находятся в `images/products/`. В каждой карточке есть галерея. Состав перенесён из присланного описания и этикеток; неизвестные сведения не подменены предположениями.

Цена `null` показывается как «Цена уточняется», ссылка `null` не создаёт кнопку покупки. `priceEstimate` — исходная оценка из архива, не подтверждённая цена продажи. Перед продажей владелец указывает действительную `price` и прямую HTTPS-ссылку `externalUrl` на Авито или Telegram.

Проверки без установки сторонних зависимостей (Node.js 24):

```sh
npm test
```

Отчёт о проверке безопасности: [docs/SECURITY-AUDIT.md](docs/SECURITY-AUDIT.md). Все данные для тестов объявлений локальные; тестовые Issues не публикуются.
